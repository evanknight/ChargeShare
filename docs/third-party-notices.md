# Third-party tooling

The `.agents/skills/openspec-*` files and `.agents/skills/.openspec-target` were generated by the official [Fission-AI/OpenSpec](https://github.com/Fission-AI/OpenSpec) CLI, version 1.14.0. Generated skills declare MIT licensing in their metadata. The upstream [MIT notice](licenses/openspec-MIT.txt) is retained for those generated files. OpenSpec is a development dependency, not application code.

Security scanning uses [Gitleaks](https://github.com/gitleaks/gitleaks) under its MIT license. Its executable is not committed. Refer to the pinned upstream revision and official release source in the security tooling.

The project's own licensing remains undecided. No project's private code, personal correspondence, live vehicle payloads or proprietary integration implementation was copied into this scaffold.
